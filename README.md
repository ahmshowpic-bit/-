# مركز الصيانة — نظام إدارة مخزون قطع غيار الموبايلات

نظام محلي بالكامل (Local First) لإدارة مخزون قطع غيار صيانة الموبايلات، مبني بـ HTML/CSS/JavaScript خام (بدون Framework) و IndexedDB لتخزين البيانات داخل المتصفح.

## طريقة التشغيل

1. فك ضغط الملفات في مجلد واحد (حافظ على بنية المجلدات كما هي: `css/`, `js/`).
2. افتح ملف `index.html` مباشرة في المتصفح (يعمل بدون إنترنت وبدون خادم).
3. عند أول تشغيل سيتم تحميل بيانات تجريبية (شاشات وقطع لموديلات شائعة) لتجربة النظام فورًا.

> إذا واجهت أي قيود على IndexedDB عند الفتح المباشر بصيغة `file://` في متصفحك، شغّل خادمًا محليًا بسيطًا من داخل المجلد (مثال: `python3 -m http.server` ثم افتح `http://localhost:8000`).

## هيكل المشروع

```
index.html
css/
  style.css       التصميم الأساسي والألوان والمكونات
  responsive.css  تكيف الواجهة مع الموبايل والتابلت
js/
  utils.js        دوال مساعدة (تنسيق، بحث، تنبيهات)
  db.js           طبقة IndexedDB (تخزين دائم)
  state.js        إدارة الحالة في الذاكرة + الحفظ التلقائي
  inventory.js    الأصناف والمخزون والبحث والفلاتر
  repairs.js      عمليات الصيانة وخصم القطع تلقائيًا
  customers.js    العملاء
  suppliers.js    الموردين
  reports.js      التقارير والإحصائيات
  settings.js     الوضع الليلي، قفل PIN، النسخ الاحتياطي المشفر
  app.js          التوجيه، اللوحة الرئيسية، البحث السريع، الاختصارات
assets/           (فارغ حاليًا، جاهز لأي أيقونات/شعارات مستقبلية)
```

## اختصارات لوحة المفاتيح

- `Ctrl + K`: فتح البحث السريع الشامل
- `Ctrl + N`: إضافة صنف جديد
- `Esc`: إغلاق أي نافذة مفتوحة

## النسخ الاحتياطي

من صفحة **الإعدادات** يمكنك تصدير كل البيانات كملف JSON (باختيار حماية بكلمة مرور تُشفّر الملف فعليًا بخوارزمية AES-256)، واستيرادها لاحقًا مع عرض ملخص قبل التأكيد.

تنبيه: قفل PIN وتشفير النسخ الاحتياطي يوفران حماية عملية معقولة، لكن لا يوجد نظام يعمل بالكامل داخل المتصفح يضمن أمانًا مطلقًا لبيانات الجهاز.

## قابلية التطوير مستقبلًا

الكود منظم بشكل Modular بحيث يسهل لاحقًا إضافة: طباعة فواتير، QR/Barcode، مزامنة سحابية، صلاحيات مستخدمين متعددين، تصدير Excel/PDF، دون التأثير على سرعة النسخة الحالية.
